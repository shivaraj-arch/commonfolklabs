How we build

Deterministic core

The facts come from parsing and arithmetic. Language models add explanation on top — never the substance. If the model is unavailable, the numbers still stand.

Public sources only

We read what is already published, and we read it without touching the systems that publish it. No scraping of live infrastructure, no private data.

Cheap enough to keep running

Built to run at near-zero cost on static delivery and scheduled jobs, so nothing depends on a funding round to stay online.

One source of truth

Web and mobile read the same generated output, so the two surfaces can never quietly disagree with each other.
